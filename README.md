# HexoMC Privacy

Official privacy-policy website for HexoMC Verification.

## Publish with GitHub Pages

1. Create a public repository named `hexomc-privacy`.
2. Upload `index.html`, `styles.css`, and `assets/` to the repository root.
3. Open **Settings > Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the default branch and `/ (root)`, then save.

The site will be available at:

`https://hexomc.github.io/hexomc-privacy/`

Configure the verification bot with:

```env
HEXOMC_DISCORD_PRIVACY_URL=https://hexomc.github.io/hexomc-privacy/
HEXOMC_DISCORD_SUPPORT_URL=https://discord.gg/422wuqJCe7
```

Support requests are handled through the private ticket system in the official
HexoMC Discord server.
